# Vehicle Rental Management System

A Java-based console application developed for managing vehicle rentals using Object-Oriented Programming principles and Core Java concepts.

## Features

- Vehicle management (Cars and Bikes)
- Customer registration
- Vehicle booking workflow
- Rental cost calculation
- Vehicle availability tracking
- File-based persistent storage
- Custom exception handling

## Technologies Used

- Java
- OOP (Inheritance, Encapsulation, Polymorphism)
- Collections Framework
- Exception Handling
- File Handling
- Serialization

## Project Structure

Vehicle -> Parent class

Car / Bike -> Child classes

Customer -> Customer details management

Booking -> Rental workflow handling

Payment -> Payment processing

Database -> File persistence layer

Admin -> Administrative operations

MainApp -> Application entry point

## Concepts Demonstrated

- Object-Oriented Programming
- Collections Framework
- File Serialization
- Exception Handling
- Modular Architecture
